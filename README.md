# scjs_multiyear_weighting
This repository contains the Reproducible Analytical Pipeline (RAP) for the creation of multiyear (MY) weights for the Scottish Crime and Justice Survey (SCJS).

## Running the RAP

The only file that needs to be updated before running the scjs_multiyear_weighting RAP is the config.R file. An example of this file with placeholder values can be found in the `scripts` folder.

To create multiyear weights, run the `SCJS_2y_weights.R` script. This file sources all required scripts and executes them.
